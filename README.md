# Personal Portfolio Website

## 📌 About the Project

This project is a personal portfolio website created using HTML and CSS.

The purpose of this website is to introduce myself, showcase my skills and projects, and provide a way for visitors to contact me.

## 🎯 Project Goals

The main goals of this project are:

* Build a personal portfolio website.
* Practice HTML5 and CSS3.
* Use semantic HTML elements.
* Apply CSS selectors and the CSS box model.
* Use Flexbox and CSS Grid for layouts.
* Practice CSS positioning.
* Make the website responsive for different screen sizes.
* Host the website using GitHub Pages.

## 🛠️ Technologies Used

* HTML5
* CSS3
* Git
* GitHub
* GitHub Pages
